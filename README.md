# BrandIntel — Free Brand Intelligence OSINT Platform

**BrandIntel** is a professional, mobile-first Brand Intelligence/OSINT SaaS platform. Enter a brand or company name and receive a comprehensive, source-backed Brand Intelligence Dossier — automatically collected from legitimate public information.

## 🚀 Features

- **One-click Brand Research** — Enter any brand name, get a complete intelligence dossier
- **Multi-source Collection** — Wikipedia, Wikidata, GitHub, RSS News, Reddit, Hacker News
- **Professional Dossier** — Identity, Web Presence, Social Profiles, News, Products, Organization, Geography
- **Transparent Scoring** — Evidence-backed visibility scoring with signal breakdown
- **Evidence Register** — Every claim linked to its source with confidence and rationale
- **Intelligence Timeline** — Chronological events with date, category, and source
- **Source Register** — Complete audit trail of all data sources
- **Export** — HTML (print-to-PDF), JSON, and CSV formats
- **Demo Mode** — Pre-built sample dossier for Acme Corporation
- **Zero Cost** — All free, public APIs. No paid services required.

## 🛠️ Technology

- **Frontend:** React 18 + TypeScript + Vite
- **Hosting:** GitHub Pages (free)
- **CI/CD:** GitHub Actions
- **Storage:** Browser localStorage / IndexedDB
- **Data Sources:** Wikipedia API, Wikidata SPARQL, GitHub API, RSS feeds, Reddit API, Hacker News API
- **No paid APIs, no AI APIs, no database, no API keys required**
